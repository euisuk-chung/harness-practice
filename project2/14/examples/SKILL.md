# 가계부 정리 기준

영수증 한 장을 가계부 한 줄로 옮긴다. 답은 JSON 한 줄만 낸다. 설명을 붙이거나 코드 블록으로 감싸지 않는다.

답의 예: {"date": "2026-01-15", "store": "가게 이름", "amount": 8000, "category": "식비", "payment": "카드", "unread": {}}

## 칸

| 칸 | 적는 것 |
|---|---|
| date | 결제한 날. 영수증에 적힌 날을 YYYY-MM-DD 로 |
| store | 가게 이름. 영수증 위쪽의 상호 |
| amount | 실제로 낸 돈(합계). 쉼표와 「원」 없이 숫자로 |
| category | 아래 분류 표의 이름 하나 |
| payment | 카드 또는 현금 |
| unread | 비운 칸마다 이유. 예: {"store": "윗부분이 찢어져 상호가 보이지 않음"} |

## 분류

| 분류 | 넣는 것 |
|---|---|
| 식비 | 식당 · 분식 · 배달 음식 |
| 장보기 | 마트 · 시장에서 산 식재료와 생활용품 |
| 카페 | 커피 · 음료 · 디저트 가게 |
| 교통 | 택시 · 버스 · 기차 · 주유 |
| 생활 | 약국 · 세탁 · 미용 · 문구 |
| 기타 | 위 어디에도 맞지 않는 것 |

## 판단 절차

1. 영수증에서 날짜 · 가게 이름 · 합계 · 결제 수단을 찾는다.
2. 보이지 않거나 흐려서 읽을 수 없는 칸은 짐작해서 채우지 않는다. 빈 문자열("")로 두고 unread 에 이유를 적는다.
3. 적힌 글자를 그대로 옮긴다. 날짜나 금액이 이상해 보여도 고치지 않는다. 형식이 맞는지는 기록하기 전에 ledger.py 가 검사한다.
4. 분류는 가게 종류로 정한다. 아래 「내 규칙」이 있으면 그것을 먼저 따른다.

## 내 규칙

- 커피 가게에서 산 케이크 · 빵도 식비가 아니라 카페로 둔다.
