# 기준 문서 확인에 쓴 지난 사례 — 프로젝트 1 블로그

확인 프롬프트의 [판단할 새 글] 에는 아래 「새 글」 줄만 넣는다. 「사람 판단」 은 가정한 블로그 운영자의 예시 판단으로, 확인을 실행하기 전에 미리 적어 둔 것이다.

| 새 글 | 사람 판단 |
|---|---|
| 1. 한 회사가 새 이미지 모델을 오늘부터 API 로 쓸 수 있게 했다는 글 | 담음 |
| 2. 한 회사의 인턴 채용 공고 | 뺌 |
| 3. 한 회사가 연구 논문과 함께 모델과 코드를 내려받을 수 있게 공개한 글 | 담음 |
| 4. 한 회사가 앱의 무료 사용 한도를 늘렸다는 글 | 담음 |
| 5. 개발자 행사 일정과 장소만 알리는 글 | 뺌 |
| 6. 한 회사가 새 기능을 미국에서 먼저 열고, 한국은 다음 달에 연다는 글 | 뺌 |
| 7. 새 에이전트 제품을 발표하며 대기 명단 신청을 받는다는 글 | 뺌 |
| 8. 한 회사 대표가 AI 의 앞날을 전망한 인터뷰 글 | 뺌 |
