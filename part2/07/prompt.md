# 목적
같은 폴더의 판매 메모로 중고 거래 판매 글을 쓴다.

# 입력
item.md 하나만 읽는다.

# 출력 형식
판매 글만 답한다. 앞뒤에 설명 글이나 코드 블록 표시를 붙이지 않는다.
- 첫 줄은 `# ` 로 시작하는 제목 한 줄
- 가격은 `가격: 45,000원` 처럼 따로 한 줄
- 빈 줄을 빼고 10줄 이하

# 지킬 것
- 메모의 상태는 빠짐없이, 메모와 같은 뜻으로 밝힌다.
- 구성과 거래 방법은 메모에 적힌 그대로 옮긴다.

# 하지 말 것
- 메모에 없는 장점이나 사실을 지어내지 않는다.
- item.md 를 고치거나 새 파일을 만들지 않는다.
