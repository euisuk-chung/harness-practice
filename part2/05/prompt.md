# 목적
이번 주 메모에서 할 일을 뽑아, 프로그램이 읽을 수 있는 목록으로 만든다.

# 입력
같은 폴더의 note.md 하나만 읽는다.

# 출력 형식
JSON 하나만 답한다. 앞뒤에 설명 글이나 코드 블록 표시(```)를 붙이지 않는다.
{"summary": "메모 전체를 한 문장으로", "todos": [{"task": "할 일 한 줄", "when": "메모에 적힌 때"}]}

# 지킬 것
- 메모의 할 일마다 todos 에 한 줄씩 넣는다.
- when 에는 메모에 적힌 말을 그대로 옮긴다. 메모에 때가 없으면 "정하지 않음" 이라고 적는다.

# 하지 말 것
- note.md 를 고치거나 새 파일을 만들지 않는다.
- 메모에 없는 할 일이나 때를 지어내지 않는다.
